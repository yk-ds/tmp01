# GitHub プルリクエスト入門

このリポジトリは GitHub のプルリクエスト (Pull Request) を体験するためのサンプルです。

## プルリクエストとは？

プルリクエストは、変更をレビューしてもらい、承認を得るための仕組みです。リポジトリに直接 push するのではなく、変更内容を別のブランチで管理し、レビューが終わったら `main` などのメインブランチにマージします。

### おおまかな流れ

1. リポジトリを fork または clone します。
2. 作業用ブランチを作成し、変更をコミットします。
3. ブランチをリモートに push します。
4. GitHub 上で Pull Request を作成し、レビューを依頼します。
5. レビューが OK なら Pull Request をマージしてもらいます。
